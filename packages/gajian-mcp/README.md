# gajian-mcp

MCP server for [gajian](https://www.npmjs.com/package/gajian): Indonesian PPh 21 TER, December reconciliation and BPJS calculations as tools.

```bash
claude mcp add gajian -- npx -y gajian-mcp
```

Other clients: `{ "mcpServers": { "gajian": { "command": "npx", "args": ["-y", "gajian-mcp"] } } }`

Tools: `payslip`, `pph21_monthly`, `pph21_daily`, `pph21_december`, `bpjs_contributions`, `list_rules`.

Full docs: https://github.com/naufaljct48/gajian#readme. Not tax advice. MIT.
